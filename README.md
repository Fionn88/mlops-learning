# mlops-learning

## Prerequisites (Before Chapter 4)

| Requirement     | Details                                                       |
| --------------- | ------------------------------------------------------------- |
| Git​            | Installed and available in PATH                               |
| Python​         | Version 3.8+ with venv support                                |
| Docker​         | Docker Desktop installed and running                          |
| AWS Account     | Active account with IAM user (programmatic access)            |
| IAM Permissions | AmazonS3FullAccess attached to the user                       |
| AWS CLI​​       | Configured via aws configure with access key & secret         |
| S3 Bucket​      | Created for DVC remote storage (e.g., mlops-dvc-remote-<name> |
